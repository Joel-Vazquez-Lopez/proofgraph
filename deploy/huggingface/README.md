# ProofGraph — AI-Assisted Dispute Investigation

ProofGraph investigates synthetic payment disputes using evidence graphs, provenance tracking, decision-readiness evaluation, and next-best-evidence recommendations.

## Public showcase

This Space is a read-only demonstration using synthetic disputes.

- Explore dispute cases and investigation recommendations.
- Inspect evidence graphs and provenance.
- Review contradictions and decision readiness.
- No real PayPal transactions or adjudication.
- Evidence submission and AI extraction are disabled in the public showcase.

The full interactive prototype supports merchant evidence submission and reviewer-initiated AI analysis.
